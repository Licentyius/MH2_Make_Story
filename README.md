# MH2_Make_Story  
  

A makehuman 2 community plugin style extension for basic character story creation within mh2 with exporting/saving. This Requires MH2 for functionality.  
Place this one in the extension folder,(in own folder named exactly make_story) and load it via the plugin panel.  This extension will appear on the left panel and is dockable/undockable.
